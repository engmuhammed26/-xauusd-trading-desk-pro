# XAUUSD Trading Desk Pro

A cloud-based gold trading analysis desk using H4 liquidity sweeps and M15 confirmation.

## Features
- LONG, SHORT, or NO TRADE signals
- Entry, stop loss, and TP1–TP3
- Asian, London, and New York sessions
- Telegram alerts (optional)
- Manual lot sizing and manual trade execution only

## Safety
This system provides analysis alerts only. It does not place automatic trades.
